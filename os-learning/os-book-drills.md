# 自作OS学習ドリル

## 使い方

このドリルは、書籍を読みながら `asm.py` と `emu.py` の動きを確認するための練習問題。

最初から全部解こうとしなくてよい。
各章を読んだあとに、対応する項目だけを見直す。

## 基本コマンド

アセンブルする。

```sh
python asm.py hello.asm
```

単体プログラムを実行する。

```sh
python emu.py hello.bin
```

OSをアセンブルする。

```sh
python asm.py os.asm
```

OSを起動する。

```sh
python emu.py
```

バイナリを確認する。

```sh
xxd -g 1 hello.bin
```

コード中の定義を探す。

```sh
rg 'SYSCALL|PC|SP|CR|VT|PT' emu.py os.asm
```

## Drill 1: Hello, World! の機械語を見る

対象。

```asm
MOVI    R8, hello_str
SYSCALL 1
HALT

hello_str:
        .STRING "Hello, World!\n"
```

見るところ。

- `MOVI` は何バイトになるか
- `SYSCALL` は何バイトになるか
- `HALT` は何バイトになるか
- `hello_str` のアドレスはいくつか
- `R8` に入る値はいくつか

考える問題。

- `Hello` を `Hi` に変えると、命令部分は変わるか
- 文字列の先頭アドレスが `0x0000C` になる理由を説明する
- `xxd` の出力から `HALT` の4バイトを探す

## Drill 2: `asm.py` のラベル解決

見るところ。

- ラベル名をどこで見つけているか
- ラベルのアドレスをどこに保存しているか
- `MOVI R8, hello_str` の `hello_str` が数値になるタイミング
- `.STRING` の長さがアドレス計算にどう影響するか

考える問題。

- ラベルを命令より前に置いた場合も解決できるか
- 存在しないラベルを書くと、どのような失敗になるか
- 同じラベル名を2回書いたらどうなるか

## Drill 3: `emu.py` の fetch/decode/execute

見るところ。

- `PC` から4バイト読むところ
- 命令読み込み後に `PC` が4増えるところ
- `b0`, `b1`, `b2`, `b3` に分けるところ
- `op_type = b0 >> 4`
- `op = b0 & 0x0F`

考える問題。

- `MOVI R8, 0x0000C` の `op_type` はいくつか
- `SYSCALL 1` の `op_type` はいくつか
- `HALT` はどの `op_type` と `op` になるか

## Drill 4: `SYSCALL 1` で文字列が出る流れ

見るところ。

- `SYSCALL imm` がどこで処理されるか
- `do_syscall()` に渡される値はいくつか
- `R8` の値をどこで読んでいるか
- 0終端文字列をどのように読んでいるか
- 実際に端末へ書き出す関数はどれか

考える問題。

- `SYSCALL 0` と `SYSCALL 1` の違いを説明する
- 文字列末尾の `0` がないと何が起きそうか
- `R8` に間違ったアドレスを入れると何が起きるか

## Drill 5: スタックと `CALL` / `RET`

見るところ。

- `push()` は `SP` をどう変えるか
- `pop()` は `SP` をどう変えるか
- `CALL` で何をスタックに積むか
- `RET` で何を復元するか

考える問題。

- `CALL` 直前の `PC` と、スタックに積まれる値の関係を説明する
- `RET` すると次にどこを実行するか
- `SP` 初期値が変わると、どのメモリ領域を使うか

## Drill 6: フラグと条件分岐

見るところ。

- `setflags()` がどこで呼ばれるか
- Zeroフラグが立つ条件
- Overflowフラグが立つ条件
- Underflowフラグが立つ条件
- `JPZ`, `JPNZ`, `JPO`, `JPU` の判定

考える問題。

- `SUB R1, R1` の後に立つフラグは何か
- `DEC` で0未満になったとき、どのフラグを見るべきか
- 条件分岐は `PC` をどう書き換えるか

## Drill 7: OS起動用の `PC = 0x80000`

見るところ。

- `emu.py` のレジスタ初期値
- `os.bin` がどこにロードされるか
- `PC` が `0x80000` のとき、どこから実行が始まるか
- `os.asm` 側で `0x80000` に対応するコードがどう置かれているか

考える問題。

- `hello.bin` で `PC = 0x80000` のままにすると、なぜ失敗するか
- OS起動用と単体プログラム用で `emu.py` の前提がどう違うか
- `Unknown opcode` はどのようなときに出るか

## Drill 8: 割り込みベクタ

- `VT` レジスタの役割
- 割り込み番号からハンドラアドレスを読む計算

- ページフォルトは何番か

## Drill 9: タスク切り替え

見るところ。

- タスクごとのレジスタ保存領域

- 次のタスクを選ぶ条件

考える問題。

- タスク切り替えで保存し忘れると困るレジスタはどれか

## Drill 10: 仮想コンソール

見るところ。

- タスクIDと仮想コンソール番号の対応
- `SYSCALL 0` / `SYSCALL 1` の出力先
- キーボード入力がどのキューに入るか

考える問題。

- タスク0とタスク1の出力が混ざらない理由を説明する
- アクティブでないVCに出力した内容はどこに保存されるか

## Drill 11: MMUとページテーブル

見るところ。

- `CR` のどのビットでMMUを有効にしているか
- `PT` レジスタの役割
- 論理ページ番号の取り出し方

考える問題。

- 論理アドレス `0x20010` の論理ページ番号はいくつか
- ページテーブルの値が `0x08` なら物理アドレスはどうなるか
- MMU無効時は論理アドレスと物理アドレスがどう対応するか

## Drill 12: ページフォルト

見るところ。

- ページテーブル値 `0xFF` の意味
- `PageFault` 例外が投げられるところ
- フォルトした論理アドレスを保存するところ
- ページフォルトハンドラに入る流れ
- `SYSCALL 41` で何を返すか

考える問題。

- ページフォルトは通常のタイマー割り込みと何が違うか
- フォルトしたアドレスを保存する理由を説明する
- ハンドラから戻った後、同じ命令を再実行する必要があるか考える
