# os_book_code

書籍「いちばんやさしい！OS自作超入門」（末安 泰三 著、日経ＢＰ 刊）で開発するOSのアセンブリコードと、アセンブラ、そのOSを稼働できるCPUエミュレータを配布するリポジトリです。アセンブラとCPUエミュレータはPythonで記述しています。

## Simple OS
Simple OSは、OS自身を含めた4つのタスクを並行稼働できるマルチタスクOSです。コード量を最小限に抑えつつも、プリエンプティブマルチタスクや、ページング方式による仮想メモリー、デマンドページングなどの機能を実装しています。書籍の解説を読みながら徐々に開発していくことで、OSの基礎を学べます。

開発には、アセンブリ言語のみを用いています。アセンブリ言語は「難しい」という印象を持たれがちですが、複雑な文法やオブジェクトコードの構造、リンク（ロード）の仕組みなどを学ぶ必要なく、CPUの命令と少しの文法さえ覚えてしまえば、すぐにプログラムを書ける利点があります。アセンブリ言語を使ってOSを開発することで、OSがCPUをどのように制御しているのかを詳細に把握できるのも、学習に向いている点です。

## CPUエミュレータ

CPUエミュレータでは、シンプルな命令セットアーキテクチャを持つ、オリジナルの32ビットCPUの動作を模しています。命令長とレジスタ長は、32ビット固定です。命令長を32ビットに収めるため、即値指定できる数値は20ビットまでにしています。アドレス幅も20ビットで、1Miバイトのメモリー空間を持ちます。ページング方式の仮想メモリーにも対応しています。ページサイズは64Kiバイトです。タイマー割り込みとページフォルトに対応していて、プリエンプティブマルチタスクやデマンドページングを実現可能です。

また、CPUエミュレータには、文字表示や文字列表示、キーボードからの文字入力などの機能を提供する「システムコール」を用意しています。システムコールは、SYSCALL命令を実行することで呼び出せます。

0～3番の仮想コンソールも備えています。仮想コンソールを利用することで、各タスクに専用のコンソールを割り当てられます。仮想コンソールは、［Ctrl］＋［]］に続いて［0］～［3］のいずれかのキーを押すことで切り替え可能です。

## 動作環境とOSの起動方法

CPUエミュレータとアセンブラを動かすには、Python 3.8以降が必要です（Python 3.11以降の利用を推奨します）。CPUエミュレータでtermiosを使った端末制御をしているため、OSは、LinuxやmacOSといったUNIX系OSでなければなりません。Windows 10/11を利用している場合は、WSL（Windows Subsystem for Linux）を利用してUbuntuなどのLinuxディストリビューションを稼働させてください。

条件を満たした環境であれば、次の手順でOSのコードをアセンブルして、CPUエミュレータで稼働できます。

```
$ python asm.py os.asm
$ python emu.py
```
